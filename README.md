## Selected Work

### [agent-witness](https://github.com/rioX432/agent-witness)

**Observability and auditing for AI coding agents.**

A Rust tool that records agent sessions and makes delegation, tool usage, token usage, and potentially destructive operations inspectable.

`Rust` · `Claude Code` · `MCP` · `Agent Observability`

### [KMP-FaceLink](https://github.com/rioX432/KMP-FaceLink)

**A Kotlin Multiplatform SDK for face, hand, and body tracking.**

One tracking API that wraps MediaPipe on Android and ARKit / Vision on iOS, with experimental JVM and Wasm targets. Extension modules map blend shapes to VRM and Live2D parameters and connect to VRM apps and VTube Studio through VMC Protocol, iFacialMocap, and the VTube Studio Plugin API.

`Kotlin Multiplatform` · `MediaPipe` · `ARKit` · `Vision` · `VRM` · `Live2D`

### [CivitDeck](https://github.com/rioX432/CivitDeck)

**A native workspace for discovering and running generative AI models.**

A Kotlin Multiplatform application spanning Android, iOS, and Desktop, integrating Civitai, ComfyUI, local generation workflows, and on-device search.

`Kotlin Multiplatform` · `Compose` · `SwiftUI` · `ONNX` · `Core ML`

### [ai-dev-templates](https://github.com/rioX432/ai-dev-templates)

**Structured workflows and guardrails for agent-driven software development.**

Reusable patterns for investigation, decomposition, implementation, verification, review, and PR workflows with context-isolated agents and automated quality gates.

`AI Agents` · `Automation` · `Verification`

## Current R&D

These are ongoing research and prototyping areas; some work is not publicly available.

### Agentic Engineering

I'm building development environments around **context, memory, orchestration, review, observability, and verification**, so that work delegated to AI agents can be inspected and repeated.

### Cross-platform Visual Systems

I'm researching native GPU rendering, shared visual contracts, and automated visual evaluation across Android, Apple platforms, and Web. Current experiments include VRM avatar rendering and interactive character experiences.

This builds on my work with **MediaPipe, ARKit, RTC, Unity, Kotlin Multiplatform, and avatar systems**.

### Creative Production Workflows

I'm exploring how Blender, 3D asset preparation, and AI-assisted tooling can fit into repeatable production workflows. The focus is on connecting modeling, materials, and runtime integration, with prototypes used to evaluate technical choices and guide implementation.
